# moodboard — 複数画像/動画ビューア(ライトテーブル)

`moodboard` コマンド(bun + webview-bun の WKWebView 窓)で開く。**サーバもブラウザも不要**。

## 開き方

```sh
command -v moodboard >/dev/null || bun install -g github:mohhh-ok/moodboard
moodboard --target <名前> <画像/動画/音声パス...>; echo "rc=$?"
```

- 前面でそのまま実行する。`nohup`・`&`・`disown` は付けない。ウィンドウは moodboard 自身が別セッションの子プロセスで開くので、ツール呼び出しが終わっても残る。ランチャーは表示を確認して数秒で終わる
- `--target` は HTML の `target="xxx"` と同じ。同じ名前のウィンドウが開いていればその中身を差し替え(位置はそのまま)、無ければその名前で新しく開く。名前はウィンドウのタイトルにも出る
- 作り直した画像は毎回別のファイル名(時刻や版番号を付ける)で渡す。同じパスに上書きして同じ `--target` へ差し替えると、`opened ... 差し替え` が出ても古い画像のまま表示される(画像は `file://<パス>` で読み込まれ URL が変わらないため、WKWebView のキャッシュが出ると見られる)
- 名前は作業ディレクトリ名(プロジェクト名)で始める。並べて見比べたいときは用途を足す(例: `billionclips`、`billionclips-before` と `billionclips-after`)。名前は英数字と `. _ -` だけ
- `--target` を省くと毎回新しいウィンドウになる。窓がたまるので、エージェントは必ず `--target` を付ける
- パスは相対でもよい。スペース・日本語可
- zsh で多数枚を変数に入れて渡すときは配列にする(`FILES=(); FILES+=("$f"); moodboard --target x "${FILES[@]}"`)。`moodboard $FILES` は zsh では 1 引数になる

### セクション見出し・カードのラベルを付けたいとき(`--json`)

見出し+説明文でグルーピングしたい、各カードに文言を添えたい(比較対象の違いを一言で示す等)ときは、パスを並べる代わりに board JSON ファイルを書いて渡す:

```sh
moodboard --target <名前> --json /tmp/<プロジェクト>/board.json; echo "rc=$?"
```

```json
{
  "sections": [
    {
      "title": "take A",
      "note": "読み上げ元の台本。\n改行はそのまま保持される。",
      "items": [
        { "path": "/tmp/project/take_prod.wav", "label": "current production" },
        { "path": "take_2.wav", "label": "retake 2" }
      ]
    }
  ]
}
```

- `sections` は必須・空不可。各セクションは「見出し(`title`)+説明(`note`、任意・改行保持)→そのカード群」の1ブロックとして上から並ぶ
- `items` は必須・空不可。`path` は絶対パスか JSON ファイルのディレクトリ基準の相対パス。`label`(任意)未指定ならファイル名が出る
- 未知のキー・型違い・空配列・存在しないパスは、窓を開く前に rc=1 で拒否される
- `--json` とパス列挙(`moodboard <パス...>`)の併用は rc=1 のエラー
- 完全な形式・検証ルールは [README](https://github.com/mohhh-ok/moodboard) の「Board JSON」節が正

### 「開いた」と報告してよい条件

終了コードが 0 で、`opened target=<名前> pid=<PID> 新規|差し替え images=<枚数>` が出たときだけ。この行はページが全画像の読み込みを終えた通知を受けてから出る。同じパスを上書きして差し替えた場合は、この行が出ても中身が古いことがある(上の「作り直した画像は毎回別のファイル名で渡す」)。

- `1` = 引数の誤り、または存在しないパス(一覧が出る)
- `2` = 20 秒以内に表示を確認できなかった(新規なら log のパスが出る)
- `3` = 開いたが読み込めない画像があった(一覧が出る)。そのままユーザーに見せず、原因を先に見る

## 閉じる・一覧

```sh
moodboard --close <名前>   # その名前のウィンドウだけ閉じる
moodboard --list           # 開いている名前付きウィンドウ
```

## 絶対にやらないこと

- **`pkill -f moodboard` 等で全体を閉じない**。別のプロジェクト・別のインスタンスのウィンドウまで閉じる。閉じるのは `--close <自分の名前>` だけ
- 他のプロジェクトの名前を `--target` に使わない(そのウィンドウの中身を上書きする)

- **`open "file://...?クエリ"` 禁止**。macOS の LaunchServices がクエリを落とし空表示になる(実害あり)
- **Playwright MCP でこのビューアを開かない**(file: ブロックあり。かつ Chrome チャネル起動で
  ユーザーの Chrome と衝突した実害あり)
- 表示した画像を勝手に `rm` しない

## UI 仕様

- **wheel** = カーソル位置を不動点に画像自体をリサイズ(上=拡大。Google Maps と同じ向き。ピンチ対応)
- **drag** = 自由移動(クリッピングなし。重ねて比較可。掴んだものが最前面)
- **click**(ドラッグなしの素のクリック)= ライトボックス(`0`=fit `1`=物理等倍 `2`=200% `←/→`=前後 `space`=動画の再生/一時停止 `m`=音の切替 `Esc`=閉じる)
- `r` = 再整列 / `b` = 背景切替(ダーク→市松→白。透過確認は市松) / slider・`+`/`-` = 基準サイズ。ウィンドウのリサイズでも自動で再整列される(連続発火は間引く)が、前回の整列後にドラッグ移動や wheel リサイズで手動配置したカードが1つでもあると、それを崩さないよう自動再整列はスキップされる(手動配置後に戻したいときは `r`)
- `⌘W`(`Ctrl+W`)= ウィンドウを閉じる(ライトボックス・選択モード中でも効く。`--close` と同じくプロセスが終わり pid ファイルも消える)
- `s` = 選択モードのトグル。モード中は各アイテムにチェックボックスが出てクリックでトグル、「コピー」で選ばれた画像の**絶対パスを改行区切り**でクリップボードに入る。`⌘/Ctrl+A` = 全選択、`⌘/Ctrl+C` = コピー、`Esc` = モードを抜ける。並べたものからパスを抜き出して他コマンドに食わせる用途向け
- 物理 200% 以上で自動 `image-rendering: pixelated`(ドット検品用)
- 画面と CLI のエラーメッセージは macOS の言語設定に合わせて日本語か英語で出る(日本語以外は英語。`$LANG` は見ない)。ユーザーが別の言語を望んだときだけ先頭に `--lang ja|en` を付ける。英語表示ではボタン・表示の文言も英語になる(「コピー」→ Copy、「再生不可」→ Can't play)
- 各カードの下にラベル(`--json` の `label`、未指定ならファイル名)が出る。board を渡したときはセクションごとに見出し+説明文が上から積まれ、`r` の再整列でこの配置に戻る
- 動画(mov/webm/mp4、拡張子判定)は自動再生・ミュート・ループで表示され、上記の操作すべてが画像と同じに効く。ライトテーブル上は常にミュート(複数同時に鳴るとうるさい)で、音はライトボックスで 1 本ずつ出る(既定で音あり・`m` でミュート切替)。ライトボックスで動画を開く(またはミュート解除する)と、再生中の音声カードは自動で一時停止する(ここでも同時に鳴るのは1本だけ)。ライトボックスの動画には音声カードと同じ見た目の操作バー(再生/一時停止ボタン・シークバー・経過/総時間)が付き、一時停止やシークバーのクリック・ドラッグで好きな位置へ飛べる。操作バーの上のドラッグ・wheel・クリックで動画の移動・拡大・ライトボックスを閉じる操作は起きない。画像を開いたとき・再生不可のときは操作バーは出ない。声・台詞の検品はライトボックスで行う。alpha 付き待機ループ動画の見比べに使える(市松背景で透過確認)。HEVC alpha の `.mov` は再生できるが、VP9 alpha の `.webm` は再生できないことがあり、その場合は「再生不可」+ファイル名の表示になる
- 音声(wav/mp3/m4a/aac/flac/ogg/opus、拡張子判定)はカード自体が再生/一時停止ボタン・シークバー・経過/総時間を持つプレイヤーになる。カードのクリック(ボタン以外の領域でも)で再生/一時停止をトグルでき、どれかを再生すると他の音声は自動で一時停止する(同時に鳴るのは1本だけ)。カードの高さは操作 UI に合わせた固定で、基準サイズでは幅だけが変わる(縦に間延びした空箱にならない)。wheel ではリサイズしない(スクロール中に思わず伸び縮みしないように。カードの上でもページがスクロールする)。再生中のカードは枠が緑になり、背景にも緑みが付き再生ボタンも緑になるので、選択状態(青い outline)と重なっても判別できる。drag での移動は画像・動画と同じに効くが、ボタン・シークバーの操作がそれを誤発火させることはない。音声カードはクリックしてもライトボックスは開かず、ライトボックスの `←/→` は音声を飛ばす。選択モード中も再生ボタン・シークバーは再生・シークに使え、カードのそれ以外の場所のクリックが選択トグルになる(聴きながら選べる)。再生できないファイルは「再生不可」+ファイル名の表示になる

## 備考

- 窓を閉じればプロセスも終わる。状態ファイルは `/tmp/moodboard-<uid>/`(権限 700。他ユーザーは触れない)(targets に名前ごとの pid、logs に新規起動のログ、boards に board JSON。boards は読まれ次第すぐ消えるので基本空)
- ビューア本体の変更・検証手順は [docs/development.md](https://github.com/mohhh-ok/moodboard/blob/main/docs/development.md)
